## Bugs found and fixed

The workspace selector could display Production while the active context and request credentials were for the sandbox. Session refetch recreated option elements after the select's value assignment. Options now explicitly bind their selected state to the active context. Verified after HMR, sign-in, session verification, mutation refresh, rotation and import.

Restored or retrieved contexts could display their UUID instead of their name because key responses contain only the environment ID. The gateway now fetches authorized environment metadata before saving the context, and refreshes the name from root metadata. Verified key retrieval after forgetting the context and added a gateway regression check for restoration metadata.

## Delivery blocker

No production reminders or production webhook configuration were changed. This is browser workflow testing, not an exhaustive accessibility, cross-browser, load or penetration test.
